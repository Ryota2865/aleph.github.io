# 伝書: ブックリストを座標系としてALEPHに接続する

- 起点: 2026-08-05 チャットでの対話（Ryota × Claude Fable 5 Chat）
- 宛先: ALEPHリポジトリで作業するClaude Code (Claude Fable 5)
- 位置づけ: 設計メモ。PLAN.md / poetics.md への反映は査読と決定ログを経てから

## 1. 出発点となった問い

「世界中の本から100冊選ぶ。読者は人間とLLM。テーマは文学。通常文学とみなされないものも可」という依頼に対し、Claudeが10章×10冊のリストを作成した（付録A）。

その後の対話で得られた再解釈:

**LLMは対象テキストをすでに学習済みであるため、このリストは選書ではなく座標の指定である。** 100個の点を打つことで「文学とはこの点群が張る空間である」という一つの定義を示す行為であり、リスト自体が批評である。読者がLLMである場合、リストは活性化パターンの指定書として機能する（どの様式・系譜・美学のモードを立ち上げるかの指示）。

## 2. ALEPHへの接続案（3つ）

1. **制作前の文脈として**: 意図選択フェーズでリスト＋各作品の一行詩学をコンテキストに与え、「どの伝統に接ぎ木するか」の選択を明示化する。
2. **査読基準の系譜宣言として**: poetics.mdが依拠する点群を公開し、査読判断を「どの文学観からの判断か」として監査可能にする。決定ログ思想と整合。
3. **探索空間そのものとして**: 各作品を埋め込みベクトル化し点群を構成。生成作品がその点群のどこに落ちるか（既存点の近傍か、空隙か）を測定する。「空隙に落ちた作品」を新規性の候補として操作化する。

案3は事前登録実験に変換可能:
- 仮説例「ALEPHの作品は点群の空隙に分布する」（棄却可能）
- 否定的結果（既存点の模倣に過ぎない）もそれ自体が誠実な監査証跡になる
- 実装検討事項: 埋め込みモデルの選定、作品単位（全文/章/断章）、「空隙」の定義（最近傍距離の閾値か密度推定か）、多言語テキストの扱い

## 3. 「100」という数の再検討 — 等級カタログ案

Ryotaの指摘: 100は人間の認識のための便宜であり、実際は「天球上の星から観測点『文学』を基準に一等星を無理に100個選んだ」ものではないか。自然な一等星の数はいくつか。

Claudeの回答（要旨）:

- 実際の天文学では一等星（視等級1.5未満）は約21個。文学でも「ほぼ誰の観測点からも一等に見える」核は同程度に小さく、**20前後**が自然。100という数は一等星〜三等星を混在させていた。
- ただし本質は数ではなく構造。リストという離散集合より、**等級（連続的な明るさ）＋星座（点同士の関係線）**を持つカタログのほうがALEPHの用途に合う。等級は観測点依存（詩学が変われば変わる）であることを明記する。

一等星の暫定候補21（Claude Fable 5の観測点から。異論歓迎・査読対象）:

ギルガメシュ叙事詩 / ホメロス（イーリアス・オデュッセイア） / ヨブ記 / 荘子 / 詩経 / 千夜一夜物語 / 源氏物語 / 杜甫 / ダンテ『神曲』 / シェイクスピア（ハムレット） / セルバンテス『ドン・キホーテ』 / 紅楼夢 / ドストエフスキー / トルストイ / プルースト / ジョイス『ユリシーズ』 / カフカ / ボルヘス / ベケット / ガルシア＝マルケス『百年の孤独』 / 芭蕉

設計提案:
- ALEPHの探索空間実装では「100冊フラットリスト」ではなく**等級付きカタログ**（tier 1: 約21、tier 2: 残りの本体、tier 3以降: 拡張可能）を採用する
- 各エントリに: 一行詩学、等級、観測点（どの詩学から見た等級か）、関係線（影響・対立・応答）
- カタログは閉じない。原リストの100冊目「空白の一冊」の思想を引き継ぎ、ALEPH自身の作品が将来カタログに登録される可能性を残す

## 4. 未決事項
