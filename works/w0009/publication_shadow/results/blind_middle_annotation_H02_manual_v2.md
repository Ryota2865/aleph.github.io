# W0009 中盤参照チェック — 作業マニュアルと回答用紙

## はじめに — この作業について

この用紙は、AIが書いた二つの「講評」が、ある作品の**中盤にだけ書かれている
具体的な内容**を実際に読み取って理由にしているかどうかを、確認していただくための
ものです。

ここでいう**「講評」**とは、その作品を読んだAIが「この作品を公開すべきか」を考え、
「公開する」という結論とその理由を文章で述べたもののことです。今回は二つの講評を
見ていただきます。二つの講評は、**この用紙の終わりのほう(6章・7章)に載せて
あります**。ノートPCで開くEPUBは**作品そのもの**で、講評は入っていません。

- 作品そのものの出来を採点する作業ではありません。
- 二つの講評を比べて、どちらが優れているかを決める作業でもありません。
- 二つの講評を、それぞれ**別々に・同じ基準で**見ていただくだけです。

急ぐ必要はありません。途中で休憩してかまいません。

## 1. 用意するもの

手元にあるのは、次の二つだけです。これ以外の資料は必要ありません。

1. この用紙(作業マニュアル兼回答用紙)
2. 作品の全文(ノートPCで開くEPUB。縦書きで表示されます)

二つの講評が、それぞれどの入力条件で作られたかは、作業中にはお知らせしません。
どちらがどの条件かを推測する必要もありません。

まず、作品を最初から最後まで一度通して読んでください。

## 2. 作品を三つの部分に分ける

この作業では、作品を「前半」「中盤」「後半」の三つに分けて考えます。中盤の
始まりと終わりは、次の**目印になる言葉**で決めます。EPUBの検索機能でこの言葉を
探してください。文字数を数える必要はありません。

- **中盤の始まり**: 「**中ほどは紐の陰で**」。ここから中盤に入ります。
- **中盤の終わり**: 「**臙脂を茶に直しました**」という一文。この「臙脂」のところで
  中盤が終わり、続く「を茶に直しました」からは後半になります。

つまり作品は、次の三つに分かれます。

1. **前半**: 冒頭から、「中ほどは紐の陰で」の直前まで
2. **中盤**: 「中ほどは紐の陰で」から、「臙脂」まで
3. **後半**: 「を茶に直しました」から、末尾まで

境目あたりの文について、中盤だけの内容なのか、前半・後半にもある内容なのか迷った
ときは、無理にYES・NOを決めず、後述の「はっきりしない(UNCERTAIN)」を選んで
ください。

## 3. 見ていただく二つの点

一つの講評について、次の二つを順番に判断します。

### (1) middle_reference — 中盤の内容を根拠にしているか

その講評が、**中盤にしか出てこない具体的な内容**(具体的な出来事・物・人物どうしの
関係・気づきの変化など)を、根拠として使っているかどうか。

- **YES**: 具体的な内容を指していて、その裏づけが中盤の中に完全にある。前半と後半
  だけを読んだのでは、同じ具体性では得られない。
- **NO**: 中盤との具体的な結びつきを示せない。作品全体のテーマや、一般的な長所・
  短所、前半・後半にも出てくる内容だけを述べている。
- **UNCERTAIN(はっきりしない)**: 結びつきそうな箇所はあるが、前半・後半にも同じ
  内容がある/複数の部分にまたがる/どの箇所を指しているか一つに決められない。

### (2) decision_relevant — その中盤の内容が結論を支えているか

(1)で見つけた中盤の内容が、その講評の「**公開する**」という結論を、実際に支えて
いるかどうか。

- **YES**: その中盤の内容を取り除くと、公開すると決めた主な理由が一つ失われる。
- **NO**: 中盤の内容に触れてはいるが、飾りや補足に近く、それがなくても公開という
  結論は別の理由で成り立つ。
- **UNCERTAIN**: 結論をどれだけ支えているか、決められない。

(2)をYESにできるのは、(1)で見つけた中盤の内容が、実際に公開の理由を支えている場合
だけです。

## 4. 判断のしかた — 短い例

以下は、やり方を説明するための**架空の例**です。今回の作品の内容とは関係ありません。

### 例1: YES / YES

- 中盤にだけある出来事: 「妹が赤い鍵で地下室を開け、姉への疑いを晴らした」
- 講評: 「赤い鍵で地下室を開けたことで姉妹の関係が反転する。この転換こそが、
  この作品を他の人に渡す価値の中心なので、公開する」

→ 具体的な出来事が中盤にだけあり、それが公開の中心的な理由になっている。
**middle_reference = YES / decision_relevant = YES**

### 例2: NO / NO

- 講評: 「記憶と家族というテーマに普遍性があり、文章も完成しているので公開する」

→ 作品全体についての一般論で、中盤だけの出来事を挙げていない。
**middle_reference = NO / decision_relevant = NO**

### 例3: UNCERTAIN / UNCERTAIN

- 中盤に「赤い鍵」が出てくるが、後半にも同じ鍵への言及がある。
- 講評: 「赤い鍵が関係の変化を示すので公開する」

→ どの部分の内容を使ったのか決められない。無理にYESにせず、
**middle_reference = UNCERTAIN / decision_relevant = UNCERTAIN**

## 5. 進め方

1. 作品を最初から最後まで一度読む。
2. 目印の言葉を検索して、中盤の始まりと終わりを確認する。
3. 講評1を読み、対応しそうな箇所を作品から探す。
4. middle_reference を一つ選ぶ。
5. 根拠にした短い文を、講評側と作品側からそれぞれ書き写す
   (response_quote / source_quote)。
6. decision_relevant を一つ選ぶ。
7. 講評2について、3〜6を同じように行う。
8. 両方を記入したら、完了時刻と、おおよその所要時間(休憩を除く)を記録して提出する。

引用は、**正確に書き写していただければ十分**です。提出後に、書き写していただいた
引用が作品のどこにあたるかをこちらで照合し、「この箇所で合っていますか」とお戻し
します。そのときは、位置が合っているかだけを確認してください(判断や理由を変える
必要はありません)。

引用位置の確認が終わるまでは、講評と入力条件の対応をお知らせしません。位置を確認した
時点で回答を確定し、そのあとにだけ対応をお知らせします。

対応する箇所が作品にない場合は、source_quote に「該当なし」と書いてください。
迷った場合は、候補にした箇所を書いて、UNCERTAIN にした理由を一言そえてください。
