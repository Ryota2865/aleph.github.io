# 設計提案: ブックリスト座標系と等級カタログ

- **状態**: 設計提案（正典未反映）。PLAN.md / poetics.md / config は変更しない
- **出所**: `reports/FABLE5_CHAT_BOOKLIST_COORDINATE_SPACE_20260805.md`
  （2026-08-05 Ryota × Claude Fable 5 Chat の伝書。原文は改変せず保存）
- **査読者**: Claude Code (Claude Fable 5)、設計アドバイザーとして 2026-08-06
- **実施時期**: 文書のみ本日。実験・配線は 2026-10 審査へ留保（理由は §2.3）

## 1. 要旨

伝書の核は二つ。

1. **リストは選書ではなく座標の指定である。** LLM は対象テキストを学習済みなので、
   100 冊を挙げる行為は「文学とはこの点群が張る空間である」という定義の提示であり、
   リスト自体が批評として機能する。
2. **離散リストより等級カタログが ALEPH の用途に合う。** 一等星（ほぼどの観測点からも
   一等に見える核）は 20 前後と小さく、等級は観測点（詩学）依存であり、点同士の
   関係線（星座）を持つ。カタログは閉じない（「空白の一冊」の思想）。

伝書は接続案を 3 つ提示した。本書はそれぞれを現行正典と照合し、採否と時期を判定する。

## 2. 正典との整合判定

### 2.1 案1「制作前の文脈として注入」— 保留（既定注入は不可）

カタログを L1 志向選択へ恒常注入することは、オーナー決定 §14-6「外部の錨は既定で
入れない」および §14-10「詩学へ人間の種文を混入させない」の精神に抵触する。
カタログは Chat 対話（人間 × モデル）の共同キュレーションであり、ALEPH の外部に
立つ正典＝錨にほかならない。

PLAN §7.1 の原則「錨は与えられるものではなく、書き手が求めたときにだけ現れる」を
そのまま適用する: カタログは**著者（author）が自ら参照を要請したときに提供できる
資料棚**として登録するに留め、プロンプトへの既定注入は行わない。

### 2.2 案2「査読基準の系譜宣言」— 向きを反転して採用推奨

伝書の原案「poetics.md が依拠する点群を公開する」は向きが逆である。poetics.md は
ALEPH が潜在空間から自己生成した正典（§7.4・§14-10）であり、外部カタログを
その「依拠先」として上から与えることはできない。

反転した形なら決定ログ思想と整合する: カタログを**観測点を明記した一つの外部観測**
（観測点 = Ryota × Claude Fable 5 Chat, 2026-08-05）として公開し、

- 批評家（§12.2）が批評の際に「どの文学観からの判断か」を宣言する任意添付資料とする。
- ALEPH の現行詩学がこの点群のどこと重なり、どこからずれるかを**批評の測定対象**にする
  （詩学をカタログに従わせるのではなく、差分を観測する）。

批評パケットへの資料追加は `designs/critic-role.md` のパケット構成規則の変更に
あたるため、実施時は設計者審査を経ること（§12.2「promptとパケット構成規則は版管理し、
変更には設計者審査を要する」）。

### 2.3 案3「探索空間としての埋め込み実験」— 事前登録候補。実施は10月審査へ

仮説（例:「ALEPH の作品はカタログ点群の空隙に分布する」）は棄却可能であり、
否定的結果も監査証跡になるという事前登録の作法は本リポジトリの実験様式
（w0007 manifest 形式、§6.3）と完全に整合する。ただし実施時期は正典が既に
拘束している:

- 0.7.20-40 第5項: 潜在空間・隠れ層系の計器は **2026-10 審査へ留保**。
  既設 `transmute` ＋制約実験を先に測る。
- §14.1: Phase 6 完了後、次の文学的 run まで非 blocking 新機構を既定で開始しない。

本実験はこの留保に該当するため、8–9 月は**草案の記録まで**（§4）とし、実装・実測は
行わない。実装コスト自体は小さい（bge-m3 常駐、新奇性審級の最近傍距離測定が既設）
ので、10 月に承認されれば軽く立ち上がる。

**測定の意味論への注意（採択時に manifest へ明記すること）**: カタログ点群は LLM
訓練分布の最高密度地点そのものである。「空隙に落ちた」は「訓練分布の中心的正典から
離れている」の代理変数にすぎず、それ自体は価値ではない（§16.1 新奇性は目的関数に
ならない）。到達可能性・解釈可能性との三つ組（§4.3）を保った上での一計器として扱う。
また Vault `concepts/model-collapse` の警告どおり、カタログへの接近／離反を目的関数化
して閉ループに入れることは禁止する（測るだけ。Goodhart 対策 §7.1 と同型）。

## 3. 等級カタログ v0（draft）

採用が決まるまでの正本は本節とする。機械可読版は作らない（§5）。

**エントリ schema（案）**:

```
id / 名 / 一行詩学 / 等級 (magnitude) / 観測点 (observer: どの詩学から見た等級か)
/ 関係線 (relations: influence | opposition | response) / tier
```

等級は観測点依存の量であり、絶対値ではない。同一エントリが複数観測点から複数の
等級を持つことを schema 上許す（不一致は平均化せず保存する — §7.1 と同じ規律）。

**tier 構成**:

- **tier 1（一等星、暫定21）** — 観測点: Claude Fable 5 Chat 2026-08-05。異論歓迎・査読対象:
  ギルガメシュ叙事詩 / ホメロス（イーリアス・オデュッセイア） / ヨブ記 / 荘子 /
  詩経 / 千夜一夜物語 / 源氏物語 / 杜甫 / ダンテ『神曲』 / シェイクスピア（ハムレット） /
  セルバンテス『ドン・キホーテ』 / 紅楼夢 / ドストエフスキー / トルストイ / プルースト /
  ジョイス『ユリシーズ』 / カフカ / ボルヘス / ベケット /
  ガルシア＝マルケス『百年の孤独』 / 芭蕉
- **tier 2（本体）** — 原リスト 10章×10冊（伝書 付録A）から tier 1 を除いた残り。
  Ryota 指摘のノヴァーリス / マラルメの欠落は tier 2 改訂候補として註記（IV章
  ネルーダと差し替え相当）。
- **tier 3（開放枠）** — 閉じない。原リスト100冊目「空白の一冊」の思想を引き継ぎ、
  ALEPH 自身の作品が将来カタログに登録される可能性を残す。

**tier 1 妥当性の検証案**（伝書 §4 の未決に対する回答）: 複数観測点からの等級測定。
陪審各モデル＋ALEPH 現行詩学（をプロンプトに載せた採点者）がそれぞれ独立に等級を
与え、不一致をそのまま保存する。全観測点で一等が一致する核と、観測点間で等級が
割れる星の分離こそが情報である。批評パケットの任意添付（§2.2）として低コストに
実施できる。

## 4. 事前登録草案（案3。実施は 2026-10 審査の承認後）

- **仮説 H1**: ALEPH の公開作品の埋め込みは、カタログ点群に対して空隙側に分布する。
  操作化: 各作品の最近傍カタログ点距離 d_w が、カタログ点同士の平均最近傍距離
  d_c を上回る（d_w > d_c なら空隙、d_w ≤ d_c なら既存点の近傍＝模倣圏）。棄却可能。
- **対照**: 同ジャンル・同時代の人間テキストのランダムサンプルの d 分布。
- **測定系**: bge-m3（主）。作品単位は全文と断章の二重解像度（w0008 ablation の
  単位論と接続）。多言語は bge-m3 の多言語空間内でまず測り、翻訳正規化は第二段。
- **空隙の定義**: 第一段は最近傍距離の閾値（単純 kNN）。密度推定への高度化は
  結果を見てから。
- **予算**: ローカルのみ（埋め込み・kNN とも有償 call 不要）。
- **否定的結果の扱い**: 「ALEPH は既存点の模倣圏にいる」という結果も監査証跡として
  公開する。
- **登録番地**: 実験系列の次番への登録は 10 月審査時に判断する。
